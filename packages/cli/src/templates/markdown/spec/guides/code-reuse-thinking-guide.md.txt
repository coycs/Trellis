# Code Reuse Guide

Reuse should reduce concepts, not merely move duplication.

## Before Adding Code

1. Search for the same domain term, side effect, and data shape.
2. Prefer an existing public helper when its contract matches.
3. Extract shared logic only when two real callers need the same behavior.
4. Keep adapters thin; put policy in one implementation.
5. Delete the superseded path in the same change.

## Review

- Is there one source of truth?
- Are call sites simpler after extraction?
- Did the abstraction introduce flags for unrelated behavior?
- Can the shared contract be tested without platform setup?
- Are generated templates derived from the same implementation?
