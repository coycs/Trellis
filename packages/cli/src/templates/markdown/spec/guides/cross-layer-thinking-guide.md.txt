# Cross-Layer Guide

Use this guide when a change crosses UI, state, API, persistence, tooling, or
generated configuration.

## Trace the Contract

1. Identify the user-visible outcome.
2. Trace input, validation, transformation, persistence, and output.
3. Name the canonical type or schema at every boundary.
4. Update all consumers of a changed contract.
5. Verify the complete path with one focused integration scenario.

## Review

- Does every layer use the same field names and states?
- Can partial failure leave contradictory state?
- Is validation performed once at the authoritative boundary?
- Are stale adapters, docs, templates, and tests removed?
- Does the final test prove behavior rather than implementation details?
